# Go'jo' Satoru Profil Sahifasi

![Go'jo' Satoru Banner](https://i.imgur.com/YbqT8JK.png)

## 📋 Loyiha haqida

Ushbu loyiha "Jujutsu Kaisen" anime va mangasining eng mashhur personaji Go'jo' Satoru uchun yaratilgan zamonaviy, interaktiv va chiroyli veb-profil sahifasi. Loyiha HTML, CSS va JavaScript texnologiyalari yordamida yaratilgan.

## ✨ Asosiy xususiyatlar

### 🎨 Chiroyli dizayn
- **Modern UI/UX** - Zamonaviy va jozibali interfeys
- **Animatsiyalar** - Smooth transitions va hover effektlari
- **Glow effektlari** - Go'jo'ning Infinity (Cheksizlik) qobiliyatiga mos effektlar
- **Floating particles** - Sahifada suzuvchi zarralar animatsiyasi

### 🌓 Qorong'u/Ochqin rejim
- **Tugma orqali o'tish** - Bir klikda tema o'zgartirish
- **LocalStorage** - Foydalanuvchi tanlovini saqlash
- **Sistema preferensiyasi** - Avtomatik tizim rejimiga moslashish

### 📱 Responsive dizayn
- **Mobile-first yondashuv** - Barcha ekran o'lchamlari uchun
- **Flexible layout** - Moslashuvchan komponentlar
- **Optimal navigatsiya** - Har qanday qurilmada qulay foydalanish

### ⚡ Interaktiv elementlar
- **Smooth scroll** - Sezgir navigatsiya
- **Progress barlar** - Animatsiyali qobiliyat ko'rsatkichlari
- **Hover effektlari** - Kortinkalarga o'tganda animatsiyalar

## 🛠️ Texnologiyalar

- **HTML5** - Semantik struktura
- **CSS3** - Zamonaviy styling (Flexbox, Grid, Animations)
- **JavaScript (ES6+)** - Interaktivlik va dinamik kontent
- **Font Awesome** - Ikonkalar
- **Google Fonts** - Orbitron va Roboto shriftlari

## 🔧 Konfiguratsiya

Loyihani o'zingizga moslashtirish uchun:

### 1. Ranglarni o'zgartirish
`style.css` faylidagi `:root` va `.dark-theme` classlaridagi CSS o'zgaruvchilarini o'zgartiring.

```css
:root {
    --primary: #4a6fa5;        /* Asosiy rang */
    --secondary: #6d98ba;      /* Ikkinchi darajali rang */
    --accent: #ff6b6b;         /* Aktsent rang */
    /* ... */
}
```

### 2. Kontentni o'zgartirish
`index.html` faylidagi matn va tarkibni o'zgartiring.

### 3. Rasmni almashtirish
Asosiy tasvir uchun `index.html` faylidagi 38-qatordagi `src` atributini o'zgartiring.
